Git mengelola versi dari kode program kita. Setiap ada ubahan akan disimpan dalam git

Sejarah Git
Dibuat oleh Linus Torvalds
Ide awalnya = "Pusing karena project open source nya banyak konflik"

git -> aplikasi untuk mengelola versi kode bisa melacak siapa yang membuat atau mengubah kode. Jadi kalau ada error bisa langsung di perbaiki.

Merk lain selain GitHub.com
- Gitlab.com
- Bitbucket.org

Tahapan Kerja Git
1. Working Directory = Edit / modified code atau file in project
2. Staging Area = Fase dimana kita akan melakukan commit. Ada 2 fase :
- Git add . => staging area
- Git commit => Menyimpan ubahan file => save
3. Local Repository => Laptop kamu, Komputer kamu => Setelah commit
Analogi = flashdisk
4. Remote Repository (GitHub.com)
Analogi = google drive / cloud storage
